# F07

Kỹ thuật theo tab thiết kế: `F07ShowtimeDecisionTest.java`, mặc định dừng 2,5 giây/ca.
Chạy `selenium/run-techniques.ps1 -Feature F07`; chuẩn bị theo `selenium/TECHNIQUES-F01-F08.md`.

Phụ trách theo Sheet: Hoàng Lê Huy.
Thành viên tự viết các lớp ...Test kế thừa com.cinebook.base.BaseTest trong thư mục này.
Đối chiếu mã TC, Expected và kỹ thuật trong Sheet.
Đã có luồng chính trong `F07ShowtimeMainTest.java`. Bấm Run lớp này hoặc chạy `run-selenium.ps1 -Test F07ShowtimeMainTest`.
Thành viên bổ sung testcase chi tiết ngay trong thư mục này. Xem `selenium/MAIN-FLOWS.md` để cấu hình và xem liên kết.
